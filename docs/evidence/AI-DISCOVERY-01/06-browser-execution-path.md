# AI-Discovery-01 — 06 Chrome Gemini 경로

조사 시각: 2026-10-27 12:50 KST.  
제품 코드, 확장 프로그램, DB, 외부 연동, Production은 바꾸지 않았다.  
Gemini 페이지를 새로 열지 않았다. 쿠키, 토큰, 비밀번호는 읽지 않았다.

두 경로를 나눈다.

| 경로 | 의미 | 이번 판정 |
| --- | --- | --- |
| 사람이 Chrome에서 Gemini를 씀 | 사람이 사업 문장을 넣고 화면의 답과 출처를 본다 | 로그인 없는 텍스트 질문의 과거 화면은 있다. 웹 검색과 출처는 미검증 |
| ALABOM이 그 Gemini를 씀 | ALABOM이 사업 내용을 넘기고, 응답 원문을 저장하고, 피드백으로 2차 검토를 잇는다 | 현재 환경에서 불가. 페이지를 대신 조작해 수집하는 방식은 약관상 부적합 |

첫 경로가 된다고 두 번째가 되지는 않는다.

## 1. 현재 로컬 구조에서 이미 있는 것

이 저장소와 이 클라우드 환경이다. CEO PC의 Chrome 프로필은 이 환경이 아니다.

| 위치 | 관찰 | Gemini 웹과의 관계 |
| --- | --- | --- |
| `prepareAnalysisRequest` | 프롬프트 문자열을 만든다. 문구는 “ALABOM이 이 문장을 모델 API나 AI 웹 화면에 보내지 않는다. 사용자가 직접 옮긴다.” | 브라우저를 열지 않는다 |
| `acceptPastedAnalysis` | 사람이 붙인 문장 하나를 참고로 저장한다. `verifiedFact`는 false | 페이지를 읽지 않는다. `HANDOFF_BOUNDARY.readsAiPage`는 false |
| `storeWebReview` | GPT 칸과 Gemini 칸에 붙인 문장을 둔다 | 수집기가 아니다. 비교는 S1–S6·A1–A2 고정 문구만 본다 |

| 이 환경의 Chrome | `Google Chrome 156.0.8078.47`, `DISPLAY=:1` | 이번 턴에 Gemini로 실행하지 않음 |

기존 기능만으로 되는 범위는 “사람이 화면의 글을 복사해 붙여넣기 칸에 둔다”까지다. ALABOM이 Gemini 탭에 사업계획을 전달하거나, 응답 완료를 판별하거나, 출처 링크를 원문과 함께 가져오지는 않는다.

붙여넣기 칸이 있어도 `AD01-TEST-LUNCHBOX-01`의 사업 검토가 되지는 않는다. 그 한계는 `02-initial-analysis.md`의 규칙 층 실행이다.

## 2. 확장 프로그램과 기존 환경의 비교

구현하지 않았다. 비교는 설계 메모다.

| | 사람이 복사 | 기존 Playwright 실험 | 사용자 클릭 한 번의 확장 | 확장이 입력·전송까지 자동 |
| --- | --- | --- | --- | --- |
| 누가 Gemini를 조작하나 | 사람 | 스크립트 | 사람은 직접 질문. 확장은 그 다음 클릭에서 보이는 글만 읽음 | 확장 또는 스크립트 |
| 로그인 | 사람이 안 하면 비로그인 | 빈 프로필. 쿠키를 복사하지 않은 과거 실행 | 계정과 무관하게 DOM을 읽을 수 있는지는 미검증 | 미검증 |
| 응답 원문 | 사람이 복사한 만큼만 | 과거 실행은 짧은 연결 문장만 저장 | 미검증. 생성 중과 완료의 구분은 실험 없음 | 과거 수집기는 생성 중 화면을 첫 응답으로 다시 읽은 적이 있다 |
| 출처 | 사람이 링크를 함께 복사해야 함. 자동 보존 없음 | 저장된 Gemini 글에 출처 URL 없음 | 미검증 | 미검증 |
| ALABOM 연결 | 붙여넣기 칸. 사업계획 ID와 출처 원문의 연결 필드는 이 테스트에 없음 | 제품 상태에 넣지 않음 | 로컬 전달 설계만 가능. 구현 없음 | 구현 없음 |
| 2차 피드백 | 사람이 다음 프롬프트를 다시 붙임. 반영 실험은 미실행 | 두 번째 질문은 코드 `PINE-42`만 묻는다. 사업 피드백이 아님 | 미검증 | 미검증 |
| 약관 | 도움말의 사용 순서와 같다 | `robots.txt`가 막는 경로를 스크립트가 연다 | 자동 전송이 아니면 3절의 금지와 다르다. 허용으로 단정하지 않음 | 3절의 자동 접근에 해당. 부적합 |

확장을 만든다면 최소 권한은 이 메모를 넘지 않는다. 구현 승인이 아니다.

- 설치와 실행은 사람의 클릭이다.
- 권한은 그 탭의 `activeTab`뿐이다. `<all_urls>`, `cookies`, `webRequest`는 넣지 않는다.
- 읽는 대상은 사람이 이미 연 Gemini 탭의 보이는 응답이다.
- 입력칸에 대신 타이핑하거나 Submit을 누르지 않는다.
- 쿠키와 토큰을 읽거나 저장하지 않는다.
- 저장은 그 브라우저 안의 로컬 보관이다. 서버, 분석 이벤트, URL 쿼리로 사업 문장을 보내지 않는다.
- 응답이 아직 늘어나는 중이면 완료로 저장하지 않는 판별이 먼저 필요하다. 그 판별은 미검증이다.

이 메모만으로 “확장이 있으면 제품 흐름이 된다”고 보지 않는다. 읽기 확장이 약관에 맞는지, 비로그인 검색 결과를 안정적으로 끝으로 판별하는지는 추가 조사다.

## 3. 공식 근거와 이미 있는 화면

### 3.1 로그인 없이 쓸 수 있다고 적힌 범위

출처: https://support.google.com/gemini/answer/13275745?hl=en&co=GENIE.Platform%3DDesktop  
확인: 2026-10-27 KST.

- 일부 기능은 로그인 없이 쓸 수 있다. 추가 기능과 활동 저장은 Google 계정이 필요하다.
- 기기와 지역에 따라 비로그인 범위가 달라질 수 있다고 적는다.
- 비로그인에서 막힌다고 적은 예: 지난 대화, 개인화, Connected Apps, 이미지 생성, Gems, 파일 업로드.
- 모델 수동 전환은 로그인이 필요하다고 적는다.
- 웹 검색의 비로그인 제공 여부와 출처 표시는 이 페이지에 없다. 미확인.
- 비로그인 입력 길이, 응답 길이, 반복 횟수, 리셋 시각은 이 페이지에 없다. 미확인.

한도와 컨텍스트 32k, 5시간 갱신은 `01-candidate-matrix.md`의 로그인 구분 없는 앱 한도다. 비로그인에 같은 숫자가 적용되는지는 미확인.

### 3.2 자동 접근

`https://gemini.google.com/robots.txt` 를 2026-10-27 KST에 읽었다.

```text
User-agent: *
Allow: /app/download
Disallow: /app/
Disallow: /chat/
```

Google 약관은 웹페이지의 기계 판독 지시(robots.txt가 크롤링 등을 막는 경우)를 어기는 자동 접근을 금지한다.  
https://policies.google.com/terms?hl=en-US

Gemini 앱 가이드는 데이터 마이닝·스크래핑을 위한 대량 생성을 위반 예로 든다.  
https://support.google.com/gemini/answer/18481641?hl=en

그래서 `run-anon.mjs`처럼 `/app/`을 스크립트로 열고 글을 읽는 방식은 다시 실행하지 않는다. 제품 경로로 쓰지 않는다.

Chrome 웹스토어 정책은 확장의 단일 목적, 최소 권한, 설치 전 고지, 사용자 데이터는 그 목적 안에서만 쓰기를 요구한다. 브라우징 활동 수집은 그 기능이 스토어 페이지와 UI에 드러난 범위를 넘으면 안 된다.  
https://developer.chrome.com/docs/webstore/program-policies/policies

이 정책이 “사람이 누른 뒤 한 탭의 글을 읽어도 된다”까지 허용한다고 단정하지 않는다. 자동 전송을 허용하는 문장도 없다.

기록: `docs/evidence/ALABOM/AI-PM/BROWSER-REPEAT-ROUNDTRIP-POC-2026-10-16.md`  
저장: `experiments/browser-anon-roundtrip/last-run.json`  
화면 파일: `experiments/browser-anon-roundtrip/shots/gemini-01-opened.png`, `gemini-02-response1.png`, `gemini-03-response2.png`

2026-10-16 빈 프로필 Chrome에서 로그인 없이 입력칸이 열렸고, 연결 문장만 오갔다. 저장된 Gemini 글은 다음뿐이다.

- `Connectivity test successful. Your code is PINE-42.`
- 이어서 `PINE-42`
- 화면 문구 `Sign in to connect to Google apps, create images, and more`

사업계획, 웹 검색, 출처 URL, 피드백 반영은 그 실행에 없다. 규칙 모의 응답이 아니라 당시 화면의 짧은 답이지만, 사업성 검토 검증으로는 세지 않는다. 첫 실행은 생성 중 화면을 첫 응답으로 다시 저장해 왕복 성공이 아니었다. 수집 안정성도 그때 깨졌다.

2026-10-27에 그 이미지와 JSON을 다시 읽었다. Chrome을 Gemini에 다시 붙이지는 않았다. 오늘 Chrome 버전은 156.0.8078.47이고, 과거 기록의 브라우저는 154였다. 오늘 지역·계정 정책의 재현은 아니다.

## 5. 가장 단순한 확인 절차

자동 스크립트는 뺀다. `run-anon.mjs`를 실행하지 않는다. 확장을 설치하지 않는다.

CEO Chrome에서만 할 최소 단계다. 이 클라우드 에이전트의 브라우저로 대신하지 않는다.

1. 평소 쓰는 Chrome에서 시크릿 창을 연다. Gemini에 로그인하지 않는다.
2. 주소창에 `https://gemini.google.com/` 을 넣고, 사람이 직접 연다.
3. 입력칸이 없으면 거기서 멈춘다. 로그인 요구만 적는다.
4. 입력칸이 있으면 `01-candidate-matrix.md`의 `AD01-TEST-LUNCHBOX-01`과 1차 지시문만 붙여 넣고 사람이 전송한다.
5. 답이 끝나면 화면의 문장과, 보이는 출처 링크를 빠짐없이 로컬 메모에 복사한다. 링크가 없으면 “출처 없음”이라고 적는다.
6. 같은 화면에서 `AD01-FEEDBACK-01`을 이어서 보내고, 2차 문장도 같은 방식으로 복사한다.
7. 로그인 유도, 한도, 오류가 나오면 그 문구를 적고 우회하지 않는다.

그 메모가 생기기 전에는 ALABOM에 붙이지 않는다. 붙여넣기 칸은 원문 보관이지, 검색이 됐다는 증거가 아니다.

## 7. 최종 판정

- 로그인 없이 사람이 텍스트를 보내는 기능: **추가 조사 필요.** 공식 문서는 일부 가능하다고 적고, 과거 화면은 연결 문장만 있다. 웹 검색과 출처는 미검증이다.
- ALABOM이 Gemini 페이지를 열어 응답을 가져오는 연결: **약관 또는 기술상 부적합.** 현재 제품은 그 연결이 없고, 있는 실험 스크립트는 robots가 막는 `/app/`을 자동화한다.
- 사람 복사 뒤의 붙여넣기: 현재 코드에 칸이 있다. 그 칸은 수집 성공이 아니고, 2차 개선의 증거도 아니다.
- 별도 확장: 자동 입력은 부적합이다. 사람이 전송한 뒤 한 번 클릭으로 읽는 안은 **추가 조사 필요**이며, 이번 작업에서 만들지 않는다.

제품 목표인 “ALABOM이 실제 Gemini 결과를 보존하고 피드백 재검토까지 잇는다”는 현재 환경에서 확인되지 않았다. API와 RAG로 넘어가지 않는다.
