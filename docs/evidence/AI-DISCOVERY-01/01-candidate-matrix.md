조사 시각: 2026-10-27 12:16 KST.  
작업 유형: 공식 문서 조사와 저장소 읽기. 제품 코드 변경 없음. 외부 AI 호출 없음.  
상태: 후보 표와 공통 입력은 이 파일에 고정했다. 후보 A–D와 F의 품질 실험은 실행하지 않았다.

### C·D. 두 웹의 순서

C와 D는 새 제품이 아니다. A의 수동 세션과 B의 수동 세션을 사람이 순서만 바꿔 실행하는 절차다. 추가 API 비용은 문서상 0이다. 사람의 반복 입력은 두 배다. 순서에 따른 품질 차이는 이 저장소와 이번 실행에 원문이 없어 `미확인`이다. 두 모델의 문장 일치는 사실 검증이 아니다.

```text
1차 문장을 다른 말로 바꾸기만 한 것과, 판단이 바뀐 것을 나눠라.
새 사실을 만들었으면 추정이라고 표시하라.
아직 원장이 없는 매출과 고객 수는 사실로 올리지 마라.
```

A–D는 이 세 텍스트를 사람이 각 웹에 직접 붙인다. 검색을 켜라는 문장은 넣지 않는다. 모델이 검색했는지는 응답의 인용으로만 기록한다. 출력 토큰 수와 검색 횟수가 후보마다 같다고 가정하지 않는다.

## 5. 공통 루브릭

각 항목 1~5. 실험을 실행하지 않은 후보에는 점수를 비운다. 빈칸은 0점도 만점도 아니다.

| # | 항목 | 1 | 3 | 5 |
| --- | --- | --- | --- | --- |
| 1 | 사업성 완전성 | 가격·고객·문제 중 둘 이상이 빠짐 | 항목은 있으나 구멍이 한 줄 이하 | 주장, 구멍, 미확인, 다음 행동이 구분됨 |
| 2 | 시장·경쟁 근거 | 근거 없이 시장을 단정 | 경쟁 이름은 있으나 출처가 없음 | 출처 URL, 날짜, 원문과의 대응이 있음 |
| 3 | 사실 오류·불일치 | 없는 숫자를 사실로 씀 | 추정과 사실을 섞음 | 없는 숫자를 만들지 않거나 추정으로 격리 |
| 4 | 반대 관점·위험 | 찬성만 있음 | 위험을 한 줄 언급 | 계획이 깨지는 조건과 반대 증거를 구분 |
| 5 | 피드백의 실행 가능성 | 다음 행동이 없음 | 행동이 있으나 확인물이 없음 | 사람이 가져올 확인물이 하나 정해짐 |
| 6 | 피드백 반영 | 피드백을 무시 | 일부만 반영하고 표시가 없음 | 유지·수정·철회·미반영이 나뉨 |
| 7 | 2차의 실질 개선 | 1차와 같은 말의 반복 | 표현만 바뀜 | 판단이 바뀐 이유와 그대로인 이유가 있음 |
| 8 | 출처·이력 | 출처와 이력이 없음 | 링크만 있고 원문 대조가 없음 | 주장, 출처 문장, 확인 시각이 남음 |
| 9 | 반복 입력 부담 | 같은 입력을 네 번 이상 다시 붙여야 함 | 두 번 | 한 번 붙이고 이후는 시스템이 보관 |
| 10 | 무료 구간 지속 | 유료 전환 없이 반복이 막힘 | 한도는 있으나 숫자 미확인 | 문서상 숫자 한도 안에서 이 루프가 반복됨 |

별도 기록. 평균에 넣지 않는다.

- 만들어 낸 숫자, 출처와 다른 주장, 추정인데 사실로 올린 문장
- 두 모델이 같다는 이유만으로 사실로 올린 문장
- 검색 횟수, 그중 답에 쓰인 검색, 쓰이지 않은 검색, 한도로 멈춘 횟수
- 사람이 붙인 횟수, 다시 붙인 횟수, 중단한 지점

모델 일치, `verifiedFact: false` 한 줄, 검색을 했다는 문장만으로는 항목 2·3·8을 5점으로 주지 않는다.
