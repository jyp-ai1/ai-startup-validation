## 2. 입력 직후 — Interpretation (S1)

Left는 ①만 진행. ✓ 아님.

```text
┌ 양조장 체험 관광 서비스 ──────── [전체 사업내용 보기] ──┐
│                                                          │
│ LEFT              CENTER                    RIGHT        │
│ 진행상태          AI PM                     현재 검증    │
│                                                          │
│ ① 사업 정의  ●    AI가 이해한 내용          사업/제품 △ │
│ ② 시장 검증  ○                              실제 사용자 △│
│ ③ 사업성 검토 ○   전통주·양조장 체험을      핵심 문제 ○ │
│ ④ 결과      ○    원하는 내국인 및 외국인    결제자   ○  │
│                   관광객에게 양조장 체험과               │
│                   주변 관광을 연결하는                   │
│                   서비스로 이해했습니다.                 │
│                                                          │
│                   근거  사업내용에서 확인                │
│                                                          │
│                   [ 맞습니다 ]           ← C1            │
│                   [ 이 부분은 다릅니다 ]                 │
│                                                          │
│                                         0/4 확인         │
│                                         현재  ① 사업 정의│
│                                         판단  아직 어려움│
└──────────────────────────────────────────────────────────┘
```

금지:

```text
현재까지 이렇게 이해했습니다
+
제가 이렇게 이해했습니다
```

금지 (Right에 Center 서술 복제):

```text
RIGHT 제목: 전통주·양조장 체험을 원하는…
```

Right는 기호와 짧은 슬롯만.

접힌 Source:

```text
┌ 전체 사업내용 보기 ─ open ──────────────────────────┐
│ 다양한 관광객이 늘며, 개인별 다양한 경험을 중요시    │
│ 한다. 전통주와 양조장 체험을 좋아하는 내국인과       │
│ 외국인을 대상으로 양조장 체험과 주변 관광 경험을     │
│ 제공하려 한다.                                       │
└──────────────────────────────────────────────────────┘
```

## 3. 이해 수정 (빈 폼 금지)

```text
┌ AI가 이해한 내용 — 수정 ─────────────────────────────┐
│ 사업/제품   [전통주/양조장 체험 관광 서비스      ]   │
│ 실제 사용자 [전통주/양조장을 좋아하는 내국인·외국인] │
│ 핵심 문제   [ (AI 초안 또는 비움)                ]   │
│ 결제자      [ (비움)                             ]   │
│ 사용 맥락   [ Facet — 비어도 ① 완료를 막지 않음 ]   │
│                                                       │
│ 안내: 틀린 칸만 고치면 됩니다. 처음부터 다시 쓰지    │
│      않아도 됩니다.                                   │
│                                                       │
│              [ 이 이해로 확인 ]   [ 취소 ]            │
└───────────────────────────────────────────────────────┘
```

빈 양식 20칸, 「창업자/사업/고객/시장/경쟁」을 전부 쓰게 하면 FAIL.

## 4. 확인 후 첫 질문 (S3) — 이해 카드 없음

│ ② 시장 검증  ○    실제 사용자와 결제자      실제 사용자 ●│
│ ③ 사업성 검토 ○                             핵심 문제 ○ │
│ ④ 결과      ○    체험하는 사람과            결제자   ○  │
│                   돈을 내는 사람이                       │
│                   같습니까?                              │
│                                                          │
│                   왜 이 질문인가요 ▾                     │
│                   구매자가 비어 사업 정의를              │

## 5. 답변 후 — 상태가 바뀐 것이 보여야 한다

답변: `사용자는 관광객이고 구매자는 양조장 대표가 결제합니다.`

```text
│ CENTER                              RIGHT                │
│ 지금 확인할 것 · 핵심 문제          사업/제품 △          │
│                                     실제 사용자 △ 관광객 │
│ 관광객이 겪는 가장 큰 불편은        핵심 문제 ●          │
│ 무엇입니까?                         결제자   ✓ 양조장 대표│
│                                                          │
│ 기존 답변                                                │
│ 사용자는 관광객이고 구매자는 …      1/4 확인             │
│ [ 답변 수정하기 ]                   현재  ① 사업 정의   │
│                                                          │
│ [ 다음 답변 ]                       판단  아직 어려움    │
```

Right가 답변 전과 동일하면 FAIL.

## 6. Conflict

```text
┌ 이전 확인과 다릅니다 ─────────────────────────────────┐
│ 이전 확인  구매자 = 양조장 대표가 결제                 │
│ 새 답변    관광객이 앱에서 일정·체험을 직접 예약·결제  │
│                                                         │
│ [ 새 답변이 맞아요 ]     [ 이전 확인이 맞아요 ]        │
└─────────────────────────────────────────────────────────┘
```

해소 후 이해 카드가 아니라 **다음 질문**으로.

## 7. Stage ① 완료 → ②

Right `4/4 확인` (Canonical). Left만 바뀐다.

```text
│ LEFT                                                  │
│ ① 사업 정의   ✓                                       │
│ ② 시장 검증   ●                                       │
│ ③ 사업성 검토 ○                                       │
│ ④ 결과       ○                                       │
│                                                       │
│ CENTER                                                │
│ 사업 정의가 충분합니다. 이제 시장을 확인합니다.       │
│                                                       │
│ 지금 확인할 것 · 대안/경쟁                            │
│ 지금 이 관광객은 양조장 체험을 어디서 찾고 있나요?    │
```

「답변을 4개 해서 넘어갑니다」는 카피 금지.

## 8. Right 전용 — Center 비복제

```text

│ 사업/제품     ✓             │
│ 실제 사용자   ✓             │
│ 핵심 문제     △             │
│ 결제자        ○             │
│ 사용 맥락     ○  Facet      │
│                             │
│ 4개 중 2개 확인             │
│                             │
│ 현재 단계                   │
│ 사업 정의                   │
│                             │
│ 판단 가능 여부              │
│ 아직 판단하기 어려움        │

```

값 전문이 길면 한 줄 + 툴팁. Center 문단을 붙여 넣지 않음.

## 9. 결과 (④)

```text
┌ 사업성 검토 결과 ─────────────────────────────────────┐
│ 현재 판단     HOLD                                    │
│                                                       │
│ 확인된 사실                                           │
│ · 고객: 전통주/양조장 체험을 찾는 내국인·외국인 관광객│
│ · 구매자: (사용자가 확정한 값)                        │
│                                                       │
│ AI의 가정                                             │
│ · 시장: 개인화·미식·전통주 관광                       │
│                                                       │
│ 미확인 사항                                           │
│ · 핵심 문제의 심각성                                  │
│ · 차별성                                              │
│                                                       │
│ 핵심 리스크                                           │
│ · 결제 주체가 흔들리면 수익모델이 흔들림              │
│                                                       │
│ 추가 검증해야 할 것                                   │
│ · 핵심 문제의 현장 근거                               │
│                                                       │
│ 다음 실행/검증 항목                                   │
│ · (초기 스타트업 대표) 양조장 대표 1명 결제 의향 확인 │
│ · (사업전략 담당자) 기존 체험 상품과의 차별 한 줄     │
│                                                       │
│ [ 보고서 ]   향후 PDF 생성. 지금은 상태 명시          │
└───────────────────────────────────────────────────────┘
```

렌즈는 같은 사실을 재배치한다. 없는 사실을 만들지 않는다.

## 11. Anti-patterns (현재 Production에서 제거 대상으로 설계)

```text
A. 헤더 = Source 앞줄
B. 슬롯 값 = Source truncation
C. 이해 카드 두 장
D. 맞습니다 후 같은 맞습니다
E. 입력 직후 사업이해 ✓
F. Center 문단을 Right에 복사
G. 수정 = 빈 사업/고객/시장/경쟁 폼
H. 사용 맥락 미기입을 이유로 V3 Stage A 차단
```
