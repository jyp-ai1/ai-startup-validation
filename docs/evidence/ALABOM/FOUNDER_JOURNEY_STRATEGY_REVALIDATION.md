## Walk (Founder 행동)

양조장 체험 관광 원문을 붙여 새 프로젝트를 만들고, AI 이해 확인 → 루프 `맞나요?` Yes → 고객 질문 화면까지 따라갔다.

| Step | Founder 행동 | AI가 보여준 것 | Founder가 예상할 것 | 실제 화면 | 혼란 | 다음 행동 명확? | 사업 검토 가치? |
|------|--------------|----------------|---------------------|-----------|------|-----------------|-----------------|
| 1 | 워크스페이스 진입 | 새 프로젝트 폼 + 동일 제목 초안 여러 개 | 새 검토를 시작한다 | 제목 / Founder Context 4택 / 설명(선택) / PDF(선택) | 초안이 쌓여 있고 설명이 선택 | 부분 | 없음 |
| 2 | 원문 입력 후 검토 시작 | — | 내 사업을 읽고 판단을 시작 | 생성 후 이해 카드로 이동 | — | 예 | 대기 |
| 3 | 이해 화면을 봄 | 원문 클립을 “AI가 이해한 내용”으로 재표시. 고객 칸은 사업 문장 조각. 우측 레일이 같은 텍스트를 다시 보여줌 | 내 말과 AI 이해가 구분되고, 빠진 핵심이 보임 | 이해 카드 + 필드 + 원문 토글 + 레일 + 맞습니다/수정 | **예** — 같은 문장이 4곳 | 맞습니다는 보임. 수정이 어디를 고치는지는 안 보임 | 낮음. 판단 없음 |
| 4 | 맞습니다 | 같은 원문으로 또 `제가 이해한 사업은 「…」입니다. 맞나요?` + 입력창 + 네/아니요 + 답변 제출 | 이미 확인했으니 검토/판단 또는 빠진 핵심 하나 | 확인을 다시 물음. CTA 3개가 동시에 있음 | **예** | 아니오 | 없음 |

`아니요. 수정할게요` 경로는 이번 워크에서 누르지 않았다. CEO 발견으로 남긴다.

## A–F

| | 질문 | 답 | 근거 |
|-|------|----|------|
| A | 무엇을 입력해야 하는지 아는가? | 부분 | 폼은 있으나 설명이 선택이고 Context 4택의 결과가 안 보임 |
| B | AI가 무엇을 이해했는지 아는가? | **NO** | 이해가 원문 재출력. 고객 칸은 사업 문장 절단 |
| C | 왜 지금 이 질문을 받는지 이해하는가? | **NO** | 이해 확인 직후 같은 원문으로 두 번째 맞나요?. 그다음 고객 질문의 why는 레일/판단과 불일치 |
| D | 답이 사업 검토에 반영됐는지 아는가? | **NO** | Yes 이후 “기존 답변” = 원문. 검토 결과가 아니라 다음 gap |
| E | 언제 충분히 검토됐다고 느끼는가? | **NO** | 진행 = “n번째 질문” / 초안 / 슬롯 빈칸. 종료 조건이 질문 소진 |
| F | 결과가 의사결정에 도움이 되는가? | **NO** | 10분 안에 약점·사업성 판단이 나오지 않음 |

하나라도 NO면 컴포넌트 수정이 아니라 journey를 바꿀 수 있다. 여기선 B–F가 NO다.

## Clarity / Progress / Trust / Effort / Value

| 영역 | 관찰 |
|------|------|
| Clarity | 한 화면에 이해·원문·레일·확인 CTA·입력창이 겹침. “지금 하는 일”이 확인인지 질문인지 제출인지 갈림 |
| Progress | “확인 진행 중 · n번째 질문”. Founder가 느끼는 진행은 사업 검토가 아니라 인터뷰 턴 |
| Trust | 엔진은 Confirm Yes → customer OPEN을 지킴. 화면은 원문을 이해이자 기존 답변으로 보여 신뢰를 깎음 |
| Effort | 같은 원문을 읽고 두 번 확인하고, 문서에 이미 있는 고객을 다시 씀 |
| Value | **가장 약함.** “내 사업의 약점이 이거였구나”가 한 번도 없음 |

Value > Accuracy > UX polish. Accuracy 게이트(P0-1/P0-2)는 이미 CLOSED다. 부족한 것은 정확도가 아니라 **검토 가치**다.

## 전략 가설

```text
현재 질문형 Journey는 Founder에게 진행감과 가치가 부족하다.
```

근거: 같은 원문이 이해 / 확인 질문 / 기존 답변 / 레일에 반복되고, 확인을 두 번 한 뒤에도 사업 판단이 없으며, 진행 단위가 질문 횟수다.

대안 Journey (채택 전 가설):

```text
내 사업을 먼저 전체적으로 설명
 → AI가 이해한 것을 원문과 분리해 구조화
 → 지금 판단/리스크를 한 장으로 보여줌
 → 그 판단을 바꾸는 빈칸만 질문
```

KPI 후보: 10–15분 안에 Founder가 “핵심 약점 한 줄 + 지금 판단”을 말할 수 있는가.  
KPI 금지: 질문 수 · Gap 수 · 슬롯 정확도 · J-gate PASS.
