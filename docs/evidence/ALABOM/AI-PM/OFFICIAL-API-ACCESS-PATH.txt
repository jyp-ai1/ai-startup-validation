허용된 AI 접근 경로. 2026-10-15T06:32:25Z.

판정: 왕복은 아직 실행할 수 없다. 호출하지 않았다. 키를 넣지 않았다. 소비자 웹은 열지 않았다.
Production 잠금 SHA 0b465226. PR #198. 기준 커밋 93c16262.

고른 경로
- 분석: Google Gemini Developer API. 유료 할당량만. 모델 코드 gemini-2.5-flash. 엔드포인트는 Google 공식 API다.
- 반대 검토: OpenAI Chat Completions. https://api.openai.com/v1/chat/completions. 모델 gpt-4o-mini.
- 소비자 ChatGPT, Gemini 앱, Claude 웹은 이전 게이트의 제약 그대로 보류한다.
- OpenRouter 는 코드에 적힌 Gemini 경로다. 이번 선택에서는 공식 경로가 아니다. 키가 없고, 요청이 무상 AI Studio 로 넘어가면 아래 무상 데이터 조건에 걸린다.

이 경로는 소비자 브라우저 세션과 같지 않다. 분석, 질문, 답변, 재분석이 이어지는지는 키가 생긴 뒤의 별도 실행으로만 확인된다.

인증. 이 환경
- OPENAI_API_KEY 없음
- GEMINI_API_KEY 없음
- GOOGLE_API_KEY 없음
- OPENROUTER_API_KEY 없음
- ANTHROPIC_API_KEY 없음
키가 없으므로 호출을 시도하지 않았다. 키는 서버 환경에만 둔다. 저장소, 로그, 화면에 넣지 않는다.
OpenAI 는 Authorization Bearer 다. https://developers.openai.com/api/reference/overview
Gemini 는 API 키다. 2026-05-28 이후 AI Studio 에서 만드는 새 키는 auth key 다. 제한 없는 standard key 는 거절된다. https://ai.google.dev/gemini-api/docs/api-key

약관과 데이터
- OpenAI API 데이터는 2023-03-01 이후 학습에 쓰지 않는다. 명시적으로 공유에 참여한 경우는 예외다. https://developers.openai.com/api/docs/guides/your-data
- 같은 문서에서 /v1/chat/completions 의 남용 모니터링 로그는 최대 30일이다. 이것은 OpenAI 의 보관이다. ALABOM 의 삭제 약속이 아니다. 공개 개인정보 문장에는 삭제 기한이 없고, 이 저장소는 그 기한으로 지우지 않는다. Zero Data Retention 은 OpenAI 의 사전 승인이 필요하다.
- 소비자 ChatGPT 약관의 자동 추출 금지는 웹 Output 에 해당한다. API 는 Business Terms 의 범위다. https://openai.com/policies/row-terms-of-use/
- Gemini 무상 할당량은 제출한 내용과 응답을 Google 제품 개선에 쓴다. 사람이 읽고 주석할 수 있다. 민감한 정보를 무상 서비스에 넣지 말라고 적혀 있다. https://ai.google.dev/gemini-api/terms
- Gemini 유료 할당량은 프롬프트와 응답을 제품 개선에 쓰지 않는다. 금지 정책 위반을 막기 위한 제한된 기간의 로그는 남긴다. 기간의 일수는 그 문장에 없다. 보관 위치는 Google 또는 대리인이 시설을 둔 나라일 수 있다.
- 검색 grounding 은 프롬프트와 출력을 30일 저장한다. 이번 왕복에서는 끄고 둔다.
- 가격표의 gemini-2.5-flash 행은 무상 칸에 "Used to improve our products: Yes", 유료 칸에 "No" 라고 적는다. https://ai.google.dev/gemini-api/docs/pricing

사용 가능 여부. 문서로 확인했고 호출로 확인하지 않았다.
- gpt-4o-mini 는 Chat Completions 를 지원한다. https://developers.openai.com/api/docs/models/gpt-4o-mini
- gemini-2.5-flash 문서: 2.5 모델은 과거에 사용한 계정으로 접근을 제한한다. 새 프로젝트는 3.5 Flash-Lite 또는 3.8 Flash 를 쓰라고 한다. https://ai.google.dev/gemini-api/docs/models/gemini-2.5-flash
- 따라서 유료 키를 넣어도 2.5 가 거절될 수 있다. 거절되면 다른 모델로 바꾸지 않고 멈춘다. 모델 교체는 별도 승인이다.

게시 가격. 호출 결과가 아니므로 청구 확정이 아니다. priceStatus 는 unconfirmed 다.
- gpt-4o-mini: 입력 100만 토큰 0.15달러, 출력 100만 토큰 0.60달러.
- gemini-2.5-flash 유료: 텍스트 입력 100만 토큰 0.30달러, 출력 100만 토큰 2.50달러. 출력에는 thinking 토큰이 포함된다.
- 상한은 기존 계약 그대로다. 각 모델 슬롯 1회, 출력 1024토큰, 시간 30초, 자동 재시도 없음. thinking 이 상한을 넘으면 그 호출은 상한 검증 실패다.
- 이 상한이 지켜질 때의 한 왕복은 입력 규모에 따라 달라진다. 게시 단가로 센 자릿수는 1센트 아래다. 실제 usage 가 돌아오기 전에는 비용 0으로 단정하지 않는다.

왕복 테스트. 설계만. 실행하지 않음.
고정 입력은 합성 문장이다. 실존 창업자의 비공개 원문이 아니다.
"물류본부 발주 담당자가 주문 화면과 배송 화면이 따로라 누락이 생긴다고 말했다."
고객은 물류본부 발주 담당자, 문제는 주문과 배송이 나뉜 누락, 지불 근거는 없다.

실행 순서. 키가 있고 아래 승인이 난 뒤에만.
1. Gemini 유료 호출 1회. 검색 grounding 없음. 출력 상한 1024. 실행 ID, 반환된 모델 ID, usage, 주장, 추가 질문 하나, 인용 문구를 남긴다.
2. 반환 모델이 gemini-2.5-flash 가 아니거나 거절이면 멈춘다.
3. 그 질문 문자열을 ALABOM 질문으로 넘긴다. 테스트 답변은 "지난주 발주서 12건 중 2건이 배송 화면에 없었다."
4. 답변 레코드에 사업, 가설 h-problem, 질문 ID, 답변 본문을 묶는다. 기존 입력과 이전 답변은 유지한다.
5. 다음 Gemini 입력이 처음 사업정보, 첫 응답의 실행 ID, 이 답변 ID 와 본문을 포함하는지 본다.
6. GPT 반대 검토 1회. 첫 주장과 답변을 반박 대상으로 넣고, 창업자 원문을 지우지 않는다. 두 주장이 달라도 둘 다 남긴다. verifiedFact 는 false 다.
7. 실패하거나 응답이 없으면 재시도하지 않는다. networkCalled 는 전송을 기록한 뒤에만 true 다.

현재 코드가 이 순서를 수행하지 않는다.
- 화면의 질문은 selectNextQuestion 이 고른 journey.nextQuestion 이다. 모델이 만든 질문을 표시하지 않는다.
- analysisDelivery.status 는 not_sent 다. 사유는 모델에 이력을 보내지 않았다는 문장이다.
- OpenAI 제공자는 키가 있어도 call_not_opened 로 거절한다.
- 이번 지시는 UI 연결을 금지한다. 그래서 화면 절반은 키만으로 통과하지 않는다.

차단 원인
1. 공식 키가 없다. 호출 불가.
2. Gemini 무상 경로는 창업자 문장을 제품 개선에 쓴다. 유료 계정 확인 전에는 그 문장을 보내지 않는다.
3. 화면은 모델 질문을 받지 않는다. UI 연결은 이번 승인 밖이다.

다음 승인 항목
- 서버 전용 OpenAI 키와 유료 Gemini auth key 를 환경에 두는 일. 저장소에는 넣지 않는다.
- Gemini 프로젝트가 유료 할당량이라는 확인. 무상이면 호출하지 않는다.
- 합성 사업정보로 Gemini 1회, GPT 1회. 출력 1024, grounding 없음, 재시도 없음.
- 2.5 가 거절되면 중단. 다른 모델로 갈아타지 않는다.
- 모델 질문을 화면 질문에 넣는 변경은 별도 승인이다.
- 병합과 Production 배포는 계속 금지다.
