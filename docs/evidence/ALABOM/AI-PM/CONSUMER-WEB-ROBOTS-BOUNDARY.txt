소비자 ChatGPT·Gemini 웹을 자동으로 여는 경로는 닫혀 있다.

이 파일은 공개 robots.txt 만 읽은 기록이다. 대화 화면을 열지 않았다. 검색 12건을 실행하지 않았다. 로그인, User-Agent 위장, 공식 API, 키, 결제를 하지 않았다. 제품 코드는 바꾸지 않았다.

조회 시각
- https://chatgpt.com/robots.txt  HTTP 200  2026-10-15T02:40:55Z  4390 bytes  Last-Modified: Wed, 14 Oct 2026 20:40:36 GMT
- https://gemini.google.com/robots.txt  HTTP 200  2026-10-15T02:41:08Z

요청에 쓴 User-Agent 는 research-robots-check 이다. 브라우저나 다른 봇 이름으로 바꾸지 않았다. robots.txt 는 자동 클라이언트가 읽으라고 둔 공개 파일이다.

chatgpt.com 에서 전면을 Disallow: / 로 적은 이름
- anthropic-ai
- Claude-Web
- CCBot
- Google-Extended
- PerplexityBot
- Bytespider
- img2dataset, Omgilibot, Omgili, FacebookBot, magpie-crawler, Perplexity-User

User-agent: * 는 홈페이지 Allow: /$ 와 공개 안내 경로를 허용한 뒤 Disallow: / 이다.
대화 경로 Disallow: /backend-anon/conversation$ 가 따로 있다.
홈페이지가 사람에게 열린다는 사실과, 자동 클라이언트가 대화를 열어도 된다는 사실은 다르다.
이 조회는 홈페이지 HTML 을 다시 받지 않았다.

gemini.google.com 전문
- User-agent: *
- Allow: /app/download
- Disallow: /app/
- Disallow: /chat/

모든 자동 클라이언트에 앱 경로와 대화 경로가 금지되어 있다. /app 과 /chat 은 열지 않았다.

제품 경계
- 소비자 웹 UI 자동화를 ALABOM 의 조사 경로로 두지 않는다.
- 이름을 숨기거나 허용된 클라이언트처럼 보이는 것은 위 금지의 우회다. 하지 않는다.
- 사람이 자기 브라우저에서 직접 보고 원문을 붙이는 일은 robots 의 자동 클라이언트 규칙 밖에 있다. 그 붙여넣기 화면은 이 커밋에서 만들지 않았다.
- 공식 API 는 호출하지 않았다. 키와 비용은 별도 승인 대상이다.

연결된 브라우저 수는 이 조회에서 세지 않았다. 브라우저가 있어도 위 robots 규칙은 그대로다.
