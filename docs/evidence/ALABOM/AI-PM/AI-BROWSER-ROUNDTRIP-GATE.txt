1. 방식 선택

후보였던 소비자 AI 웹은 자동 세션으로 열 수 없다.

ChatGPT
- https://chatgpt.com/robots.txt HTTP 200. Last-Modified: Wed, 14 Oct 2026 20:47:19 GMT. User-Agent: research-robots-check.
- User-agent: * 는 공개 안내 경로만 Allow 한 뒤 Disallow: / 이다.
- Disallow: /backend-anon/conversation$ 가 따로 있다.
- 이용약관 https://openai.com/policies/row-terms-of-use/ : "Automatically or programmatically extract data or Output" 을 금지한다.
- 대화 화면을 열지 않았다. 브라우저로 사람인 척하는 우회도 하지 않는다.

Gemini
- https://gemini.google.com/robots.txt HTTP 200. User-agent: * Allow: /app/download, Disallow: /app/, Disallow: /chat/.
- Google 이용약관은 robots.txt 가 금지한 자동 접근을 금지 예로 적는다.
- /app 과 /chat 은 열지 않았다.

Claude
- https://claude.ai/robots.txt 는 User-agent: * 에 대해 /api/* 와 /lti/* 를 Disallow 한다. 대화 HTML 자체를 전면 Disallow 하지는 않는다.
- 소비자 약관 https://www.anthropic.com/legal/consumer-terms 는 API 키로 접근하거나 명시적으로 허용된 경우가 아니면 bot, script 등 자동·비인간 수단으로 서비스에 접근하는 것을 금지한다. 크롤, 스크랩, 하베스트도 금지한다.
- API 키가 없고, 자동 브라우저 세션은 그 금지에 해당한다. claude.ai 대화 화면을 열지 않았다.

Perplexity
- https://www.perplexity.ai/robots.txt 는 User-agent: * 에 Disallow: /*?*q=, /search/new, /search?*/ 를 둔다.
- 검색 질문을 자동으로 여는 경로는 이 규칙과 맞닿는다. 검색 화면을 열지 않았다.

공식 API
- OPENAI_API_KEY, OPENROUTER_API_KEY, GEMINI_API_KEY, GOOGLE_API_KEY, ANTHROPIC_API_KEY 는 이 환경에 없다.
- 공식 API 는 AI 브라우저 세션이 아니다. 키가 없어도, 있어도, API 응답을 브라우저 실사용 증거로 적지 않는다.

고른 방식: 없음. 약관과 robots 를 통과하는 자동 AI 브라우저 세션이 없다.
