원문, 출처, 실행 ID
- 원문, 실행 ID, 출처가 함께 비면 빠진 항목을 원문, 실행 ID, 출처로 보여 주고 이전 상태 참조를 유지한다.
- 원문만 없으면 빠진 항목은 원문이다. 출처만 없으면 빠진 항목은 출처다. 판단 문장은 바뀌지 않는다.
- 로컬 화면 http://localhost:3000/ko/business-validation 에서 원문과 출처를 비우면 "빠진 항목: 원문, 출처. 이전 판단을 유지한다." 가 보이고 기록 목록은 비었다. 판단 문장은 유보 그대로였다.
- 보관에 성공하면 실행 ID, 원문, 출처 표시, 수집 시각, 대상 가설이 한 기록에 남는다. 화면 예: handoff-1-2026-10-15T09:52:57.754Z, handoff-3-2026-10-15T09:52:57.980Z.
- 같은 실행 ID를 다시 보내면 상태 참조를 유지하고 원문을 바꾸지 않는다. 이 거부는 단위 테스트에서 확인했다. 화면은 보관이 성공하면 다음 실행 ID를 새로 만든다. 그래서 두 번째 문장은 첫 문장을 덮지 않고 새 ID로 남는다.
