# Evidence Repository

> LaunchLens is a **Learning Product**, not a feature factory.  
> Competitive advantage lives here — in **founder thinking shifts**, not design docs.

---

## Structure

```text
docs/evidence/
  SPRINT4_H1/          ← current sprint hypothesis
    session-01.md … session-05.md
    synthesis.md
  SPRINT{N}_H{M}/        ← one folder per hypothesis when sprint closes
```

---

## Rules

1. **One folder = one hypothesis** (e.g. Sprint 4 → H1 only).
2. **Session files** — verbatim observation during/after founder session. No product fixes mid-session.
3. **synthesis.md** — written after session 5: Evidence count, Confidence, Keep/Kill/Refine.
4. Link from `docs/LEARNING.md` when synthesis is complete.
