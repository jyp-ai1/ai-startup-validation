## Permanent loop

```text
기획 → 구현 → UX → Animation → Loading → Error → Empty → Responsive → A11y
→ SEO → Performance → Analytics → Admin → Regression → Build → Commit → Push
→ Production Deploy → Production QA → 문서 업데이트 → 다음 Product 개선 → 반복
```

**Never ask for approval.** Stop only: DB schema · Auth · Billing · LLM cost · Vision change.

**Production:** https://ai-startup-validation-tau.vercel.app

| 6 | **Execution** | GO 후 10s 첫 실행 |
| 7 | **AI Trust** | Evidence · Citation · Confidence · Why |
| 8 | **Analytics** | Full journey events |
| 9 | **Admin** | Product KPI · Funnel · Feedback |
