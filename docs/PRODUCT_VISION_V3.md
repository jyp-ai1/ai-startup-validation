# LaunchLens Product Vision v3.0

**Role:** Cursor (CEO + Senior Developer + QA + DevOps)  
**Mode:** Mission Mode · PM: GPT  
**Mission:** 대표가 매일 사용하는 AI Strategy Project Manager를 완성한다.

## Core Philosophy

LaunchLens is **not** AI chat, business plan writing, or market research tooling.

> LaunchLens is an **AI PM** that runs strategy projects with the founder.  
> Users don't ask questions — **AI leads first.**

**Implementation rule (non-negotiable):**

> **기능을 구현하지 말고, 사용자의 경험을 구현하라.**

## North Star

- **3 minutes** to start the first strategy project with AI
- Founders **open LaunchLens daily** — Morning Brief, Confidence, Decision, Progress
