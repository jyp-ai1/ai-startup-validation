## Sprint principles

Every sprint follows:

1. 기능 구현 → 2. `pnpm build` → 3. Test → 4. Commit → 5. Push → 6. Production → 7. Founder 검증 → 8. Success Report

### Quality gates

| Principle | Meaning |
|-----------|---------|
| **Founder First** | 개발자가 아닌 대표의 언어 |
| **Action First** | 분석보다 "지금 무엇을 해야 하는가" |
| **Trust First** | AI 조사 근거·판단 이유 설명 가능 |
| **Daily Habit** | 내일도 다시 열어야 하는 이유 |
| **AI PM Persona** | 하나의 AI PM과 함께 회사 운영 |
