# Evolution Queue Templates (v8)

**When:** `docs/QUEUE_STATE.md` active queue consumed or empty  
**Rule:** Every generated task must pass Vision guard in `docs/PRODUCT_COMPLETION_DIRECTIVE.md`

## Generation cycle (repeat forever)

1. **UX Queue** — Journey friction, copy, flow clarity
2. **Animation Queue** — transitions, skeleton, celebration, micro-interaction
3. **Accessibility Queue** — keyboard, focus, ARIA, contrast → 100
4. **Performance Queue** — Lighthouse ≥95 core routes, LCP/TBT/CLS
5. **Refactoring Queue** — safe simplification, no behavior drift
6. **Architecture Queue** — layers, interfaces, adapter boundaries
7. **Analytics Queue** — funnel, events, admin visibility
8. **Experiment Queue** — A/B hypotheses on Journey (Vision-aligned)
9. **Growth Queue** — Landing SEO, referral hooks (no feature sprawl)
10. **Technical Debt Queue** — lint, types, dead code
11. **AI Improvement Queue** — Thinking, Coach, Decision, Recommendation UX
12. **Product Polish Queue** — spacing, typography, unified motion

→ Return to **UX Queue**

## Feedback Queues (release milestones)

After Closed Beta · Open Beta · RC · v1.0 · v1.1 · …

Pull from: production analytics · admin feedback inbox · known issues · Journey dropoff

## Task template (each item)

- ID: `EV-UX-001` (queue prefix + seq)
- Priority: P1–P12 per directive
- Completion: full v8 Task standard (not feature-only)
- Vision check: strengthens AI Strategy PM? Journey first?

## Forbidden queue items

- Features not in Product Vision V3
- New modules unrelated to Goal→Workflow→Workspace→Decision→Execution
- "Nice to have" dashboards without Journey impact
