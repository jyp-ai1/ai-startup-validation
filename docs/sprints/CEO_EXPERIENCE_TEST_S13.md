# CEO Experience Test — Protocol (post S13)

**Gate:** 🟢 CEO READY (after Release Tag `s13-deterministic-analysis-engine-v1`)  
**Purpose:** Product experience — not architecture reopen.

## Five questions

1. 첫 화면에서 무엇을 하는 제품인지 이해되는가?
2. 왜 이 질문을 하는지 자연스럽게 이해되는가?
3. 답하면 무엇이 달라지는지 느껴지는가?
4. AI가 이전 답변을 기억한다고 느껴지는가?
5. 계속 대화하고 싶은가?

정답이 아니라 **경험**을 기록한다.

## Feedback classification

| Class | Examples | Disposition |
|-------|----------|-------------|
| **Product Feedback** | 문장·질문 길이·진행 가시성 | → S14 Backlog |
| **Architecture Bug** | 동일 입력≠동일 Decision · Evidence 없는 Insight · Rule 깨짐 | → Hotfix |

## Sequence

```text
Release Commit + Tag  →  CEO Experience Test  →  Classification  →  S14 Planning
```

Baseline for “S13 vs new feedback”: git tag `s13-deterministic-analysis-engine-v1`.
