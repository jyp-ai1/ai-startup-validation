## QA Checklist

- [ ] Google 로그인
- [ ] 내 프로젝트 진입
- [ ] 프로젝트 생성 (이름 · 검토 유형 · 설명)
- [ ] 전략 인터뷰 시작 (Guided entry copy)
- [ ] 질문 2개 진행 (한 번에 하나, 긴 Form 없음)
- [ ] Journey 표시 (문제 정의 · 고객 · …)
- [ ] Context Memory 표시 (문제 · 고객 · 가치 · 가설)
- [ ] Decision Placeholder 표시
- [ ] 새로고침 후 답변·컨텍스트 유지

## Anti-pattern check (must NOT appear)

- [ ] 긴 Report / SWOT / TAM 페이지 없음
