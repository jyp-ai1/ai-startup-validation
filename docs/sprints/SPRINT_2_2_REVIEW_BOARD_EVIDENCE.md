# Sprint 2.2 — Review Board & Evidence Workspace

**Version:** Sprint 2.2 (CPO P0)

## Sprint question

> LaunchLens가 **근거를 검토하며 의사결정을 만드는 Workspace**인가?

---

## Single goal

**다음 행동** + **근거를 읽는 경험** 완성

## Must ship (P0)

| # | Deliverable |
|---|-------------|
| 1 | **Next Action Engine** — 항상 CTA 1개, 상태 기반 전환 |
| 2 | **Dirty State** — 입력 변경 → ⚠ 최신 아님 → [다시 검토하기] |

## CPO Rules

**금지:** 입력 후 끝 · 추상 표현 · 문서형 Review Board · 근거 없는 AI 의견
